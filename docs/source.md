# Source code

Organizer is **open source**. The full code is available and you're free to
read, run, modify, and share it under the terms of its licence.

## Licence

Organizer is released under the **GNU General Public License, version 3
(GPLv3)**. In short, that means you can use, study, change, and redistribute
the code — as long as anything you distribute stays under the same licence and
keeps the source available. The complete licence text lives in the
[`LICENSE`](https://codeberg.org/mcapodici/organizer/src/branch/main/LICENSE)
file in the repository.

## Where the code lives

The source is hosted on Codeberg:

[**https://codeberg.org/mcapodici/organizer**](https://codeberg.org/mcapodici/organizer)

## No login needed to *use* the app

You don't need an account — Codeberg's or anyone else's — to use Organizer
itself. Just [open the app](/app/) in your browser. Your data stays on your own
device. See [Storage & backup](/guide/storage-and-backup) for how that works.
